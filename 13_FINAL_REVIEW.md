# Ruthless Final Review

Review the entire codebase as a senior frontend/media engineer.

Find and fix:
- architecture issues
- React anti-patterns
- memory leaks
- FFmpeg lifecycle bugs
- race conditions
- mobile UX problems
- accessibility failures
- incorrect savings calculations
- broken Compress Again
- unsupported codec assumptions
- ZIP/download bugs
- privacy violations
- unnecessary dependencies
- performance problems

For each important issue: explain it, fix it, and verify it.

Report files changed, major fixes, known browser limitations, tests run and remaining risks.

Do not call it production-ready while major known problems remain.
