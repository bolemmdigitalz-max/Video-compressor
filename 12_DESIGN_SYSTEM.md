# Design System

Create a premium media-tool UI.

Style:
- minimal
- technical
- modern
- professional
- strong typography
- generous whitespace
- subtle borders/shadows
- clear hierarchy

Avoid excessive gradients, glassmorphism, decoration, fake metrics and unnecessary animation.

Use subtle motion for upload, progress, completion and queue changes. Respect reduced motion.

Make mobile settings, previews, queue cards and download actions intentionally designed.
